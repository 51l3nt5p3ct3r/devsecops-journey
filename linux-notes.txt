Day 1 – Linux Basics
--------------------
Basic commands and file operations learned:

ls           — list directory contents  
pwd          — print working directory  
cd <path>    — change directory  
mkdir <dir>  — create a new directory  
touch <file> — create a new file (use 'ni' in PowerShell)  
cat <file>   — show file content  
cp <src> <dst> — copy file or folder  
mv <src> <dst> — move or rename file/folder  
rm <file>    — remove file  
rm -r <dir>  — remove directory recursively  
grep "<text>" <file> — search for text inside a file  
find . -name "<pattern>" — search files by name  
chmod +x <file> — change file permissions (Linux only)  
curl <url>   — download data from a URL  
wget <url>   — download file from a URL  

Practice Summary:
- Practiced creating, moving, and deleting files/folders.
- Learned how to search inside files.
- Started using Git and GitHub for version control.
